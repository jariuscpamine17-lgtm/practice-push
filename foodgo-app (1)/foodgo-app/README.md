# FoodGo.PH

A self-contained demo food delivery web app — no server or build step needed.

## Files
- `index.html` — page structure and markup
- `style.css` — all styling (design tokens, layout, components)
- `script.js` — all app logic (routing, cart, orders, auth, dashboards). Data is
  saved to the browser's `localStorage`, so it persists across reloads but is
  local to whichever browser/machine you're using.

## How to run it
Just open `index.html` in a browser — double-click it, or in VS Code install
the **Live Server** extension and choose "Open with Live Server" for
auto-refresh while you edit.
